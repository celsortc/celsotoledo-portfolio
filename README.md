## 📖 Sobre o projeto

<p>
Este projeto consiste no desenvolvimento do meu portfólio pessoal, criado com o objetivo de centralizar meus projetos, tecnologias e informações profissionais em um único lugar, facilitando a visualização e o acesso ao meu trabalho.
</p>

<p>
Além de apresentar meus projetos e habilidades, o site também oferece recursos de personalização e interação, proporcionando uma experiência mais completa e adaptada às preferências de cada usuário.
</p>

## ✨ Funcionalidades

<ul>
  <li>Alternância entre os idiomas <strong>Português e Inglês</strong>;</li>
  <li><strong>Dark Mode e Light Mode</strong> para personalização da interface;</li>
  <li>Armazenamento das preferências de <strong>tema e idioma utilizando LocalStorage</strong>;</li>
  <li>Formulário de contato;</li>
  <li>Menu de navegação adaptado para <strong>dispositivos móveis</strong>;</li>
  <li>Layout <strong>responsivo</strong> para diferentes tamanhos de tela;</li>

</ul>

## 🚀 Tecnologias

<ul>
  <li><strong>HTML5</strong> — estrutura e semântica da aplicação;</li>
  <li><strong>CSS3</strong> — estilização, responsividade, temas e animações;</li>
  <li><strong>JavaScript</strong> — interatividade, manipulação do DOM, tradução, temas e armazenamento de preferências;</li>
  <li><strong>Git</strong> — controle de versão e organização do desenvolvimento através de branches.</li>
</ul>

## 📚 Aprendizados

<p>
O desenvolvimento deste projeto proporcionou uma experiência prática em diversas áreas do desenvolvimento Front-end. Durante sua construção, pude aprimorar conhecimentos que vão além da criação da interface visual.
</p>

<ul>
  <li>Aprofundamento em <strong>HTML, CSS e JavaScript</strong>;</li>
  <li>Desenvolvimento de interfaces <strong>responsivas</strong> para diferentes dispositivos;</li>
  <li>Criação de um sistema de <strong>Dark/Light Mode</strong>;</li>
  <li>Persistência de dados utilizando <strong>LocalStorage</strong>;</li>
  <li>Implementação de <strong>tradução dinâmica</strong> utilizando um sistema baseado em dicionário no JavaScript;</li>
  <li>Manipulação do <strong>DOM e gerenciamento de eventos</strong>;</li>
  <li>Criação e integração de <strong>formulário de contato para recebimento de e-mails</strong>;</li>
  <li>Implementação de animações e efeitos;</li>
  <li>Aprimoramento do fluxo de trabalho com <strong>Git e branches</strong>;</li>
  <li>Organização e manutenção de um projeto Front-end de forma mais estruturada;</li>
</ul>
